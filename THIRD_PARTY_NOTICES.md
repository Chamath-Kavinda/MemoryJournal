## Sri Lanka public holiday data

- **Project:** [Dilshan-H/srilanka-holidays](https://github.com/Dilshan-H/srilanka-holidays)
- **Author:** Dilshan-H
- **License:** MIT. Attribution is required: the author name and the license information stay intact.
- **How it is used:** the app downloads one public JSON file per year from the project when the calendar needs it, and keeps it on the device for 7 days. The holiday files are downloaded, not copied into the app. The request carries only the year.
